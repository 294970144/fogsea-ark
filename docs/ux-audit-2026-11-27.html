P0移动端 HUD 十处元素互相压盖 HUD-M1

位置
css/style.css:675 的 @media (max-width:900px) —— 全站唯一一处窄屏规则，只改坐标不改结构
实测
390×844 下逐一量测（去嵌套子元素）：顶栏×右上按钮 3 383px²、武器卡×角色面板 2 631px²、武器卡×核心/小地图 1 898px²、手牌区×摇杆 10 885px²、×冲刺 4 900px²、×雾爆 2 718px²；另有开场横幅被三块面板压住（×武器卡 5 205 + ×角色面板 901 + ×核心 760）。截图中「方舟核心 600/600」直接压在武器卡上，「夜 0/7」被月亮按钮遮住，「拖动卡牌到地面筑防」几乎完全看不见。
影响
顶部信息不可读、核心耐久被挡、开场上手指引失效、摇杆压在手牌上方导致出牌误触——移动端实际上不可玩。
修复
不是微调坐标，而是为 ≤640px 引入分区网格重排（见 §07 重做方案）。桌面断点保持现状不动。

P0390px 下 5 张手牌互相压叠，卡名与描述完全不可读 HUD-M2

位置
js/06-hand.js:42 layoutHand() + css/style.css:11 --cw:128px
实测
手牌行可用宽 370px，5 张 128px 卡需要 640px。算法允许负间距（spacing=(avail-cw)/(n-1)），实得每张间隔 40–69px → 相邻重叠 67–76px；首卡 x=-6 已出血到屏幕外。截图里只剩「木」「箭」半个字。
影响
分不清牌 = 打不出牌 = 核心操作失效。
修复
窄屏改为横向滑块：卡宽 76px、间距 8px、容器 overflow-x:auto; scroll-snap-type:x mandatory，卡面只留图标+费用+一行名字，选中/拖拽时再展开为完整卡（现有 #dragCard 已具备放大浮层，可复用）。layoutHand() 增加 if (narrow) return 分支走滚动排版。

P0提示条（toast）压住阶段横幅（banner） FB-1

位置

P0视口禁缩放，而界面里存在 8–11px 文字 A11Y-1

位置
index.html:5 maximum-scale=1.0, user-scalable=no
实测
样式表 159 处 font-size，其中 8px×5、8.5px×2、9px×6、9.5px×4、10px×15、10.5px×15、11px×16。小屏 + 低 DPI 设备上既看不清也放不大。

06做得好的地方（别在重构里丢掉）

  • 键盘是一等公民。所有弹窗 Esc、确认框 Enter、黎明 1/2/3、手牌 0–=、图鉴 ↑↓ 全覆盖，且 button:focus-visible 有琥珀描边——比多数商业网页游戏强。
  • 危险操作有二次确认。重新开始 / 返回标题 / 覆盖存档 / 删除存档全部走 pauseConfirm / askConfirm，删除还做了「再点一次确认」的 arm 态。
  • 失败态想过。存档损坏有横幅 + 留存备份说明；结算写入失败会回滚火种而不是发空气；图鉴空搜索有「雾中没有这条记录」。
  • 降级链路完整。prefers-reduced-motion 关震动与命中停顿，WebGPU→WebGL→Canvas2D 三级回退，visibilitychange 自动暂停。
  • 性能意识在生活中。HUD 用 _t/_v/_n 脏标记跳过重绘，读档时 clearHudCache() 统一失效——这种细节在 UI 层很少见。

11验收清单（可逐条勾）

  • 390 / 428 / 768 三个宽度下，HUD 面板矩形两两不相交（脚本断言）
  • 390px 下 5–12 张手牌均能读到卡名与费用，第 12 张可通过横向滑动到达
  • 顶部状态条同时显示「阶段 + 日/夜 + 秒数」，进度条语义随昼夜切换标签
  • banner 与 toast 同时出现时无文字重叠（人工 + 截图对比）
  • 熔铸：拖拽悬停即显示产物名、品质、手续费；雾晶不足时显示差额并禁止松手提交
  • 刻印空槽有占位文案，点击已装刻印可看效果（触屏也能看）
  • 主菜单：无存档时「继续」disabled 且文案说明；有存档时显示第几日/何时
  • 非游戏状态不出现 #touchUI；游戏内不再出现 WASD 等键鼠文案
  • 全部 6 个弹窗：打开焦点落首位、Tab 循环、Esc 关闭、关闭后焦点归还触发按钮
  • #toasts 有 aria-live，三条主 bar 有 role=progressbar 与 aria-valuenow
  • 页面可双指缩放（移除 user-scalable=no），且不影响拖牌（#cv 已有 touch-action:none）
  • 字号收敛到 7 档后，无元素在 320px 宽度下换行破版
  • 「槽位」仅指刻印槽，「存档位」仅指存档；全局检索无混用
  • 血条文字对比度 ≥ 4.5:1（或移至条外）
