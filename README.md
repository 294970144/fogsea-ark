# 雾海方舟 · Fogsea Ark

> 孤灯不灭，守过七夜雾潮。

一个纯前端、零依赖的网页生存射击游戏。Canvas 2D 等距渲染，桌面键鼠支持完整通关；移动端适配暂停。

## 快速开始

**方式一 · 下载即玩**

前往 [Releases](https://github.com/294970144/fogsea-ark/releases) 下载最新版本压缩包，解压后双击 `index.html` 即可。

**方式二 · 本地起服务**

```bash
git clone git@github.com:294970144/fogsea-ark.git
cd fogsea-ark
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

无需构建、无需安装依赖、无 `package.json`。

> 建议使用 Chrome / Edge / Safari 最新版。标题字体走 Google Fonts，离线时会退化为系统字体，不影响游玩。

## 核心循环

| 阶段 | 内容 |
| --- | --- |
| 黎明 | 3 选 1 拾获卡牌 → 3 选 1 获得祝福 → 抽满手牌 |
| 白昼（70 秒） | 采集资源、拖卡构筑、修复核心，可按 `N` 提前入夜 |
| 夜晚 | 雾潮自岛缘刷新，构筑牌封存，仅可打出瞬发牌 |
| 结算 | 第七夜击溃雾潮之主即胜利；核心耐久归零即失败 |

胜利后可在结算页选择 **继续守护** 进入无尽模式，从第八夜起继续，难度缓增封顶。

| 狂澜 · 怒涛 | ×1.25 | ×1.3 | ×1.25 | ×1.5 |

## 卡牌

- **开局武器**：在「出航准备」页选择剑、火焰法杖、冰法杖或奥术法杖；点击即选定，本局固定，HUD 显示当前武器。
- **武器槽位**：剑 3 槽、法杖 6 槽。点击 HUD 武器卡任意位置展开槽位。把带刻印标签的手牌拖入槽位即装填，拖出槽位即卸下回手牌——卡是实体，在手牌与槽位间移动，牌库总量不变；拖到已有刻印的槽则两者交换。法杖开局预装一枚对应法术刻印，牌库不再生成同款；剑不能装法术刻印。
- **刻印牌**：锋锐（武器伤害 +20%）、迅捷（武器攻速 +15%）、回响（武器攻击 25% 概率追加一次）为数值刻印，只能装槽、不可拖地释放；火/冰/奥术法术及带刻印标签的法术牌既能装槽，也能当瞬发牌拖地释放。槽内法术按从左到右轮发，空槽则法杖停火。刻印从牌库抽取，不再由黎明赠送。
- **费用即资源**：普通牌消耗木材 / 石料 / 雾晶；法术牌消耗雾能（法师转职后为法力），不引入第二种货币。
- **两种出牌方式**：拖拽卡牌到地面松手，或先点选卡牌再点击地面。
- **落地预览**：可放置为白色半透明，不可放置为红色半透明并提示原因。
- **建筑留场，卡牌回库**：打出箭塔 → 建筑永久存在 → 卡牌进弃牌堆 → 洗牌后可再次抽到。
- **手牌上限**：初始 5 张，「扩容」+1，最高 10；法师转职后初始 7 张，最高 12；到顶后该牌永久退场。
- **拆解回收**：5% / 10% / 20% 三档累加，最高 80%，按回收率返还被移除卡牌的造价（向下取整）；到顶后退场。
- **熔铸**：把一张手牌拖到另一张手牌上松手即可熔铸（拖拽中可熔的牌会亮起「熔铸」标记）。两张源牌**永久离场**（不进弃牌堆，牌库净减 1 张），产物**直接进当前手牌**可立即使用；每次额外支付 5 雾晶。产物为「稀有 / 史诗」品质，只能由熔铸获得，不能在黎明奖励中出现，也不能再次作为熔铸源。
- **品质**：三档，每档两色成对 —— 普通（白+绿）、稀有（蓝+紫）、史诗（橙+红）。卡面左上角显示档位名，稀有以上另加档位双色描边；图鉴详情有「品质」行。
- **开局保底**：首手必含木墙与箭塔。

熔铸配方（6 组，前 3 组任取对应元素的牌即可）：

| 产物 | 品质 | 来源 | 效果 |
|---|---|---|---|
| 霜火交攻 | 稀有 | 任一火牌 + 任一冰牌 | 2 格内 34 伤害 + 灼烧 2 + 冰缓 2（可连锁蒸汽爆炸） |
| 烬纹 | 稀有 | 任一火牌 + 任一奥术牌 | 1.8 格内 30 伤害 + 灼烧 2 + 奥术标记 1（可连锁共鸣扩散） |
| 霜纹 | 稀有 | 任一冰牌 + 任一奥术牌 | 1.8 格内 28 伤害 + 冰缓 2 + 奥术标记 1 |
| 凝神 | 稀有 | 灯焰护盾 + 战术重整 | 3 秒无敌 + 抽 2 张 |
| 陨星雨 | 史诗 | 箭雨 + 雾晶雷 | 2.9 格内 78 伤害 + 强力击退 |
| 生生不息 | 史诗 | 愈灵之泉 + 修补术 | 回 45 生命 + 核心 +120 + 全部建筑 +60 耐久 |

构筑物有五种：木墙、箭塔、愈灵图腾、雾晶炮、法力之井（法师）。瞬发牌与工具牌覆盖输出、治疗、护盾、扩容与拆解。

### 法师与法术

第 2 日黎明固定出现一次职业卡「法师」；仅剑路线可转职，未选则第 3/4 日仍有概率出现，第 5 日起不再出现。法术武器无需转职。

- 转职后：法力上限 100→200，回复 14→19/秒；生命上限 ×0.6；手牌上限 +2。
- 火 / 冰 / 奥术三系法术完整实装；雷系只保留接口，不出卡牌与天赋。
- 火器范围灼烧，直接命中的敌人和树会把火传给相邻的敌人与树，蔓延一跳；烧毁的树正常掉木材。冰器普攻叠加冰缓，奥器普攻高频命中单个目标。
- 引火术、霜痕、奥术针均加入普通奖励池，所有路线可选。
- 法术武器无需转职，也不会获得转职的属性变化、法力之井或法师天赋，但保留高级法术卡获取资格，使用雾能施放；火球、冰锥、奥术冲击由对应武器免费自动释放，不再作为卡牌获取。
- 元素反应：法术武器自动开启；剑路线需法师天赋「元素融合」。火+冰=蒸汽爆炸，奥术+任意=共鸣扩散。

## 操作

| 键位 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动守灯人 |
| 自动 | 所有武器优先攻击范围内最近的敌人；范围内没有敌人时自动采集 |
| 拖拽 / 点击卡牌 | 出牌，`1`–`9`、`0`、`-`、`=` 分别选第 1–12 张 |
| 拖一张手牌到另一张手牌 | 熔铸（可熔时目标牌亮起「熔铸」标记） |
| 拖刻印牌入武器槽 / 拖出槽位 | 装填 / 卸下刻印 |
| 空格 | 冲刺（含无敌帧） |
| `N` | 提前入夜 |
| `Q` | 雾爆新星（消耗 60 雾能 / 法师为 60 法力） |
| `F` | 核心旁修复方舟（+70 耐久） |
| `M` | 静音开关 |
| `K` | 随时存档（选择存档位后确认） |
| `S` | 暂停界面存档 |
| `P` / `Esc` | 暂停 · 取消选牌 |
| 右键 | 取消选牌 |
| 滚轮 | 缩放视野 |

顶栏提供 **提前入夜 · 1×/2× 变速 · 静音 · 暂停**。移动端控制入口保留，适配暂停。

「出航准备」页与暂停界面均可打开 **雾海图鉴**：按角色、资源、卡牌、雾裔、祝福、传承、术语分类检索，每条目详情下方列出其能力标签（火/冰/奥术、范围/单体、治疗/抽牌/防御…，以及武器/刻印），含搜索框与解锁进度。

## 成长

- **局内**：黎明祝福永久被动生效，共 16 种基础祝福，分普通 / 稀有 / 传说三档 —— 雾刃、疾风、迅击、长锋、灯芯、磁石、苦修、燃灯、回魂、雾爆强化、迅影、荆棘、会心、双弦（剑专属）、灯塔共鸣、晨读。转职法师后额外解锁 25 种法师天赋（元素专精、回能护盾、法力湍流、元素风暴、魔能涅槃等）。
- **局外**：结算获得「文明火种」，在「出航准备」页购买锋刃 / 坚韧 / 仓廪三条传承，跨局生效。
- **存档**：局外进度存于 `localStorage` 的 `arkmist_v3`（余烬、传承、最佳记录、图鉴、难度、静音、当前武器，白名单逐项校验）。单局进度另存于 `arkmist_slots_v1`，最多三个存档位：第 1 日与每日黎明结束后自动写入当前槽，暂停界面或 `K` 键可手动存档，`1`/`2`/`3` 选槽、`Esc` 返回。主菜单「继续」可读取任意存档位；胜负结算后清除当前槽。读档恢复已发生的随机结果与世界地形，后续随机不保证与原时间线一致。

## 技术

- Canvas 2D 等距渲染，画家算法排序，地表离屏烘焙
- 敌人以趋近向量 + 分离力避让 + 卡死绕行行进，圆体碰撞滑移，杜绝卡死
- 空间网格加速碰撞与索敌，粒子对象池，像素比上限 2
- 特效叠加层 `FX`：WebGPU（原生 WGSL）优先，WebGPU 不可用时回退 three.js WebGL；两者都不可用时静默跳过特效，不回退 Canvas 2D
- WebAudio 实时合成音效与生成式氛围和弦
- 单 `requestAnimationFrame` 循环驱动全部状态，倍速时按步长拆分模拟

### 回归测试

```bash
node tests/regression.js
```

仅用 Node 内置模块，在 `vm` 沙箱中加载 13 个玩法脚本（不含 FX / three），以桩替身模拟 DOM、Canvas 与存储，跑完 26 个聚焦用例（R0–R25）。
